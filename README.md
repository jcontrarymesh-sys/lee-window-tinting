# Lee Window Tinting — Deployment Package

Static responsive website, four divisions, and separate brand archive. Deploy the repository root on Vercel with Framework Preset **Other** and no build command.

## Branding
Header and footer load the **same** `assets/brand/lee-logo-horizontal.svg`; favicon uses `assets/brand/lee-logo-symbol.svg`. All master variations are archived under `brand-master-archive/`. Note: these vectors are reconstructions of the approved image and should be checked against the reference before costly print production.
