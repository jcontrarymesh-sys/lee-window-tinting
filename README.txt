LEE WINDOW TINTING — RECOVERY BRAND ASSET KIT

Contains the approved supplied logo reference images, a crop of the supplied branded architectural scene, and a patch script for the recovered original website.

This is a PARTIAL repair: it restores the header/footer logo and hero image without redesigning the page. It does not invent missing residential/commercial/glass/slider photos. Those need authentic assets to finish the website.

To apply to a local checkout of restore-original-pre-copilot:
1. Place this folder alongside your checkout.
2. Open a terminal in the checkout root.
3. Run: python ../lee-repair-kit/apply_repair.py
4. Review before committing. Backups of index.html and styles.css are created.

No GitHub or Vercel changes are made by this kit.
